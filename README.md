# FOR YOU — Official Website

一个以幻想冒险题材为方向的二次元游戏官方网站前端模板。采用 React + Vite，深色幻想视觉、暖金色点缀，包含首页主视觉、世界观、角色档案、游戏特色、新闻资讯和下载入口。

## 本地运行

需要安装 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可预览。

## 生产构建

```bash
npm run build
npm run preview
```

## 页面结构

- 首页 Hero：品牌主视觉与行动按钮
- 世界观：场景介绍
- 角色：角色档案卡片
- 游戏特色：探索、羁绊、冒险
- 最新情报：公告与开发日志
- 下载区域：正式上线后替换下载地址

## 替换图片素材

目前视觉素材均为 CSS 占位区域，不依赖外部图片。素材目录和建议尺寸见 `public/images/README.md`。请将你拥有使用权的游戏原画、角色立绘和场景图放入对应目录，再将 `src/App.jsx` 中的 `ImagePlaceholder` 替换为图片组件。
